### Act I: In Which a Physicist Wanders Into Machine Learning

I studied Physics (B.Sc., University of Mumbai),
where "it works" is not an answer.
"Why does it work?" is the answer.
So when my model runs, I don't celebrate.
I get suspicious. Then curious. Then I celebrate.

### Act II: In Which Things Are Built, Broken, and Fixed

My learning method has three steps:

1. Build it.
2. Break it. (Not on purpose. Mostly.)
3. Fix it, and act like step 2 never happened.

Everything pinned below, I designed and shipped myself.
No syllabus, no shortcuts, just me and a lot of error messages
that I now consider old friends.

### Act III: The Creed

> *Carpe diem.* Seize the day.
> Then write tests for it.

Thoreau went to the woods to "live deliberately."
I go to the terminal to do the same,
with fewer ponds and more `pip install`.
